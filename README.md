# 📈 IT Stock Price Prediction App

A Streamlit web app that predicts the next trading day's closing price for Indian IT sector stocks using a Random Forest model.

**Stocks covered:** TCS · Infosys · Wipro · HCL Tech · Tech Mahindra

## Files
- `app.py` - Streamlit app
- `train.py` - Model training script
- `data/` - Historical stock CSVs
- `model/` - Trained model files
